# Запуск аналитики и CV

## Дашборд на сохранённом журнале

[Команды установки и запуска](../README.md#запуск-на-сохранённых-данных) используют только зависимости API. Вызов `python scripts/init_db.py` создаёт таблицы и справочники, затем `python scripts/load_windows_from_jsonl.py` импортирует журнал. По умолчанию используется `depot_analytics.db` в корне. Для другой базы задайте `DATABASE_URL` до выполнения обеих команд и запуска Uvicorn. Повторный обычный импорт добавляет те же строки ещё раз.

При работающем API эти запросы можно выполнить из второго терминала.

```bash
curl -fsS http://127.0.0.1:8000/health
curl -fsS 'http://127.0.0.1:8000/api/windows/?limit=1'
curl -fsS http://127.0.0.1:8000/api/metrics/current_state
```

`POST /api/windows/batch` принимает пачку окон от внешнего клиента. [Демонстрационный клиент](../scripts/sample_client.py) отправляет шесть искусственных окон для проверки API. Скриншот в README получен до такой проверки, на журнале из репозитория. На Windows для активации созданного окружения PowerShell использует `.\.venv\Scripts\Activate.ps1`.

## Обработка собственного видео

Требуются пользовательский детектор с порядком классов из `class_to_role`, веса Pose, видеозапись, OpenCV с GUI и окружение PyTorch/Ultralytics с CUDA. [requirements.txt](../requirements.txt) содержит исходный набор версий проекта. В текущей ветке нет видео депо, весов обеих моделей и разметки `data.yaml`. Операции ниже описывают штатные точки входа для подготовленного стенда.

| Сценарий | Подготовка | Команда из корня |
| --- | --- | --- |
| Первый фрагмент записи | В `runfile/log.py` укажите `VIDEO_PATH`, `DETECT_MODEL_PATH` и `POSE_MODEL_PATH` (YOLO11s-Pose). По умолчанию предел 60 с. | `python runfile/log.py` |
| Аннотированное видео и журнал | В `runfile/run3pose.py` задайте свои пути к видео, весам детектора и YOLO11x-Pose, выходному MP4 и **новому** JSONL. Этот скрипт дописывает журнал. Проверьте полигоны и интервалы движения поезда под свою запись. | `python runfile/run3pose.py` |

Первый вариант пишет файл `<имя_видео>_logs.jsonl` рядом с исходным видео. Чтобы увидеть новый журнал в дашборде, импортируйте его через `python scripts/load_windows_from_jsonl.py --path /путь/к/журналу.jsonl`. Поступление окон в БД происходит при импорте или HTTP-запросе клиента.
